#### **<u>Sumas de Variable</u>** 

Cuando se suman (x+y+z…………..) o se combinan linealmente (ax+by+cz…….siendo a,b,c ЄR) variables aleatorias independientes, la suma de las mismas es una nueva variable aleatoria que la denominaremos con la letra “W”. 

Para trabajar con este concepto de sumas de variable debemos tener en cuenta lo siguiente: 

- Cuando las variables originales que se suman (o combinan linealmente) siguen  una distribución normal entonces la variable “W” también sigue una distribución normal, ya que la suma de variables normales origina variables normales. 

- Cuando las variables originales no siguen una distribución normal o bien se desconoce la distribución de las mismas, si la cantidad de variables que se suman(o combinan linealmente) es lo suficientemente grande (o sea mayor a 20) la variable sigue una distribución normal, esto se conoce como el **TEOREMA CENTRAL DEL LIMITE.**
