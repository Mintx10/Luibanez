## **<u>Otra clasificación</u>** 

Dentro de las **variables cualitativas** , las mismas se pueden clasificar en ordinal o nominal. 

**<u>Nominal</u>** : Cuando las categorías no sugieren ningún orden. **<u>Ordinal</u>** : Cuando las categorías sugieren algún orden 

Dentro de las **variables cuantitativas** , las mismas se pueden clasificar en discretas o continuas. 

**<u>Discretas</u>** <u>: Cuando entre dos valores de variables cualquiera</u> exista una cantidad finita de valores intermedios. **<u>Continua</u>** : Cuando entre dos valores de variables cualquiera exista una cantidad infinita de valores intermedios.
